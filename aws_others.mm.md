# AWS Additional Services
## Application Integration
- **Amazon SQS** `queues processing tasks`
- **Amazon SNS** ` pub/sub notification system`
- **AWS Step Functions** `workflow orchestration`
- **Amazon EventBridge** `event routing`
## Developer Tools
- **CodeCommit** `stores source code`
- **CodeBuild** `builds applications`
- **CodeDeploy** `deploys applications`
- **CodePipeline** `orchestrates deployment processes`
## Machine Learning and AI
- **Amazon SageMaker** `provides machine learning capabilities`
- **Amazon Rekognition** `provides image and video analysis`
- **Amazon Comprehend** `provides natural language processing`
- **Amazon Lex** `provides conversational AI/chatbot engine`
## Analytics
- **Amazon Athena**`provides serverless query service`
- **Amazon Redshift** `provides data warehouse service`
- **Amazon Kinesis** `provides real-time data streaming`
- **AWS Glue** `ETL data processing`
## Management and Governance
- **CloudWatch** `provides monitoring and observability`
- **AWS Config** `provides configuration management`
- **AWS CloudTrail** `provides API activity logs`
- **AWS Systems Manager** `provides operational automation`
## Business Applications
- **Amazon Connect** `provides contact center functionality(handle calls, chats, and tasks)`
- **Amazon WorkDocs** `provides document management`
